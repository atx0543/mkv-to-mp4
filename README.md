# MKV → MP4 変換アプリ

## Web版

Webアドレス: https://atx0543.github.io/mkv-to-mp4/

ブラウザでMKVを選び、変換してMP4を保存できます。Node.jsやFFmpegのインストールは不要です。動画は外部へ送信しません。最初の変換時にjsDelivrからFFmpegの変換エンジン（約31MB）を読み込むため、インターネット接続が必要です。

Web版にはアプリ側のファイル容量制限はありません。ただし、ブラウザや変換エンジンのメモリ上限、端末の空きメモリ、動画形式によって変換に失敗する場合があります。大容量・長時間の動画には以下のパソコン版をご利用ください。

index.htmlはShift_JISです。Web変換用のFFmpeg部品を追加しています。ライセンスはTHIRD_PARTY.mdとLICENSE.ffmpeg.txtをご覧ください。

## パソコン版

Windowsで使う、HTML画面のローカル動画変換アプリです。動画は外部に送信せず、このパソコン内のFFmpegで処理します。

## 最初の準備

1. このリポジトリの **Code → Download ZIP** からダウンロードして、ZIPを展開します。
2. [Node.js公式サイト](https://nodejs.org/)からLTS版をインストールします。
3. [FFmpeg公式サイトのWindowsダウンロード案内](https://ffmpeg.org/download.html#build-windows)からWindows用FFmpegを取得します。例えばGyanのessentialsビルドのZIPを展開し、binフォルダの **ffmpeg.exe** を、このアプリの **server.cjsと同じフォルダ** にコピーします。

FFmpeg本体はこのリポジトリには含めていません。すでに手元にあるffmpeg.exeを同じフォルダに置く方法でも使えます。

## 使い方

1. **起動.cmd** をダブルクリックします。
2. MKVファイルを選択し、変換方法を選びます。
3. **MP4に変換する** を押します。
4. 完了後、**MP4を保存する** を押します。
5. 終了するときは **停止.cmd** をダブルクリックします。

パソコン版のHTMLを直接開くだけでは変換できません。ブラウザ画面を閉じてもエンジンは動き続けるため、停止.cmdを使ってください。パソコン版の変換処理はGitHub Pages上では動きません。Webで使う場合は上記のWeb版を開いてください。

## 変換方法

| 方法 | 内容 |
| --- | --- |
| 通常変換 | H.264 / AACへ再圧縮。再生しやすい形式ですが、時間がかかり画質が変化します。 |
| 高速変換 | 映像・音声を再圧縮せずMP4にまとめます。元の形式によって失敗したり、再生できない場合があります。 |

最初の映像と最初の音声のみを対象にします。字幕・追加音声・添付ファイルは含みません。HDRや特殊な色形式では色の見え方が変わる場合があります。元のMKVは変更しません。

大きい動画には元動画と変換後の動画を保存できるディスク空き容量が必要です。変換中はスリープさせないでください。変換中の中止ボタンを用意していますが、ファイル読み込み中は中止ボタンを使えません。

## ファイルと文字コード

- MKVからMP4.html: Shift_JIS。日本語UI、ダークテーマ、スマホ幅に対応。
- server.cjs: Node.jsのローカル変換サーバー。127.0.0.1だけで待ち受けます。
- 起動.cmd / 停止.cmd: Shift_JIS。
- 起動.ps1 / 停止.ps1: UTF-8 BOM。

変換結果は「作業データ」に残ります。MP4を保存し、アプリ停止後に不要な作業データを削除できます。動画・作業データ・起動URLはGitに含めない設定です。

## 確認したこと

Windows上のEdgeで、短いテストMKVの通常変換・高速変換、MP4の読み取りと保存、壊れた動画のエラー処理を確認しました。パソコン幅・スマホ幅の表示を確認しています。すべてのMKV形式や長時間・大容量動画での動作を保証するものではありません。

## 外部ソフトウェア

Node.jsとFFmpegはそれぞれの提供元のライセンスが適用されます。FFmpegのライセンスはビルド構成によって異なるため、取得した配布物に付属する説明を確認してください。
